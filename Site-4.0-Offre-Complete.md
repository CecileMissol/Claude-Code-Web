## Processus de livraison

**Pendant le dev :** mon ordi + Claude Code → mon GitHub → mon Vercel (preview client).

**À la livraison :**
1. Le client crée ses comptes (GitHub, Vercel ou Hetzner, Sanity) — assisté par un guide PDF
2. Transfert du repo GitHub au client
3. Connexion Vercel au repo (ou déploiement sur son VPS via Coolify)
4. Configuration Sanity Studio avec les accès client
5. Pointage du nom de domaine + SSL
6. Session de formation (selon palier)
7. Remise du « Kit de livraison » : accès, documentation, guide CMS

## Workflow 1 — Prospection par prototype

### Critères de ciblage (scoring)

| Critère | Poids | Signal positif |
|---|---|---|
| Pas de site ou site très obsolète | ★★★ | Design années 2010, non responsive, erreurs |
| Bons avis Google (4+ étoiles, 20+ avis) | ★★★ | Business qui tourne, mal représenté en ligne |
| Activité à forte valeur / panier élevé | ★★★ | Artisan premium, cabinet, resto, hôtel |
| Présence active sur réseaux sociaux | ★★ | Investit déjà dans le digital, matière disponible |
| Zone géographique pertinente | ★★ | Proximité pour crédibilité locale |
| Secteur non-saturé en offres web | ★ | Éviter les secteurs trop démarchés |

### Process (temps cible : 2h par prototype)

**Étape 1 — Identification (~15 min/prospect, par batch)**
Google Maps + filtres. Recherche par secteur + ville. Check : note, avis, qualité du site. Scoring.
Automatisation : script/n8n qui scrape Google Maps, vérifie le site, teste PageSpeed, génère shortlist.

**Étape 2 — Collecte de matière (~10 min)**
Google My Business, Facebook/Instagram, site existant, presse locale.

**Étape 3 — Prototypage express (~1h30)**
Claude Code + template de base. Architecture type : hero, services, témoignages/avis, contact.
Déploiement sur `[nom].site40-demo.fr`.

**Étape 4 — Contact (~5 min)**
Décisionnaire via Societe.com / LinkedIn. Message email ou LinkedIn DM.

**Étape 5 — Suivi**
Relance douce à J+5. Pas plus. Prototype non-converti → portfolio.

### Template de message

> Objet : J'ai imaginé votre futur site web
>
> Bonjour [Prénom],
>
> Je suis tombée sur [Nom de l'entreprise] en [contexte] et j'ai été impressionnée par [élément spécifique et sincère].
>
> Je me suis dit qu'une entreprise comme la vôtre méritait une vitrine en ligne à la hauteur. Alors j'ai pris quelques heures pour imaginer ce que pourrait donner votre site web :
>
> 👉 [lien vers le prototype]
>
> C'est un prototype — sans aucun engagement de votre part. Si ça vous parle, je serais ravie d'en discuter.
>
> Belle journée,
> Cécile

### Métriques

- Prototypes envoyés / mois (cible : 10-20)
- Taux de réponse (cible : 15-25 %)
- Taux conversion en projet (cible : 5-10 %)
- Temps moyen par prototype (cible : <2h)

## Workflow 2 — Stratégie SEO/GEO initiale

### Process

**Étape 1 — Atelier client (30 min)**
Comprendre activité, cible, zone géo, concurrents, objectifs. Formulaire structuré en amont + call court.

**Étape 2 — Recherche de mots-clés (~1h, semi-automatisé)**
Outils : Google Search Console, Keyword Planner, Ubersuggest, Claude.
Livrable : 15-30 mots-clés classés par priorité.

**Étape 3 — Audit concurrentiel express (~30 min)**
Top 3-5 résultats Google sur les mots-clés cibles. Structure, forces, faiblesses.
Automatisation : script récupérant URLs, PageSpeed, pages indexées.

**Étape 4 — Plan de contenu et architecture SEO (~30 min)**
Mapper mots-clés sur pages. Balises title/meta. Contenus manquants → feuille de route mensuelle.

**Étape 5 — Implémentation technique (pendant le dev)**
Schema markup, robots.txt, sitemap XML, alt tags, Hn, maillage interne, Search Console + Google Business.

### Livrable client

Document 1-2 pages : 10-20 mots-clés cibles priorités, architecture SEO, plan de contenu 6-12 mois, config technique effectuée.

## Workflow 3 — Reporting mensuel (Tableau de bord)

### Architecture technique

```
┌─────────────────────────────────────────────┐
│              SOURCES DE DONNÉES              │
│                                              │
│  Plausible Analytics       ─── API ──┐      │
│  Google Search Console     ─── API ──┤      │
│  Google PageSpeed Insights ─── API ──┘      │
└──────────────────────┬──────────────────────┘
                       ▼
┌─────────────────────────────────────────────┐
│              N8N (orchestrateur)             │
│                                              │
│  Cron : 1er de chaque mois                  │
│  Pour chaque client :                        │
│    1. Récupérer données trafic               │
│    2. Récupérer positions SEO                │
│    3. Récupérer score PageSpeed              │
│    4. Compiler les données                   │
│    5. Claude API → commentaires + suggestions│
│    6. Générer rapport (HTML)                 │
│    7. Envoyer au client par email            │
│    8. Copie à moi pour monitoring            │
└─────────────────────────────────────────────┘
```

### Contenu du rapport

**Section 1 — Trafic :** visiteurs uniques (vs mois précédent), top 5 pages, sources de trafic, temps moyen.
**Section 2 — Performance :** score PageSpeed mobile + desktop, temps de chargement.
**Section 3 — SEO (si option) :** positions mots-clés, évolution, contenu publié.
**Section 4 — Suggestions IA :** 2-3 recommandations concrètes basées sur les données.

### Format

V1 : email HTML stylé (rapport dans le corps de l'email).
V2 (à 5+ clients) : mini dashboard web `rapports.site40.fr/[client]` avec graphiques interactifs.

## Canal tertiaire — LinkedIn organique

Posture exploratrice / carnet de bord. 3 posts/semaine :
- 40 % carnets de bord (retours d'expérience, process, découvertes)
- 30 % avant/après (transformations concrètes avec storytelling)
- 20 % réflexions de terrain (observations, questions ouvertes)
- 10 % coulisses tech (stack, workflow, outils)

## Canal optionnel — Google Ads

Budget test : 300-500 €/mois. Mots-clés : « création site web [ville] », « refonte site internet [ville] ».
